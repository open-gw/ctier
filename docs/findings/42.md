## C1 — drafted from the PRD, then both tests

PRD: Classification precedes routing. No governed
operation reaches its target before a decision is
recorded.

**Mechanism or property?** Mechanism, until
restated. "Recorded" is a ledger write — the same
residue 11a removed from C10. The property is: no
governed operation reaches its target unclassified.
Compile-time binding and request-time classification
both satisfy it. The record is evidence, not the
criterion.

**And within what scope?** The PRD already said
"governed operation." Same scope sentence as C12.
A path reachable but absent from the composition
is outside.

25 classified this letter from the engine PRD
without noticing the sentence was not in this
specification. 26 concluded C1 was not a restatable
mechanism — about that same sentence. The method
held; the corpus of documents it ran against did
not.

## C4 — drafted from the PRD, then both tests

PRD: The human is never in the request path. No
decision path blocks on human input. The
enforcement point must not hold a connection open
pending a human decision.

**Mechanism or property?** The first body sentence
is the property. The title and the connection
sentence describe the architecture — where a human
sits, and how occupancy appears on HTTP. Occupancy
is already C5 and the suspension-consult rule.
Neither stated C4. The criterion is: no decision
path blocks on human input. That is what would
fail if someone added a synchronous approval call.

**And within what scope?** Deliberately unbounded.
A bound to the governed set would permit a
synchronous approval of an unknown path.

Writing C4 did not expose a gap in the reference.
The implementation already decides without waiting.
What it exposed is that the central claim had no
requirement sentence, and that occupancy language
had been standing in for it.

## The observation this set earns

A criterion can be referenced, tested against, cited
in an audit, classified, and discussed across a
dozen tasks without ever having been written down.
C1 was audited, restated-and-not-restated, and
counted — all while absent from the document it
belonged to.

The tell: it appeared only in a list of names. **A
name that never appears beside a requirement is not
a requirement**, cheaper check than either standing
question — one pass looking for every identifier
the specification uses and confirming each has a
sentence.

Worth doing now for every other identifier:
profiles, dispositions, deployment levels, record
types. Third artefact class to turn out unstated;
first two found by accident.

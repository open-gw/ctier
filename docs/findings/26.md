# 26 — C1 states the property, not the record

Spec still **1.8.0**. Requires 25. **Stopped after Part 0.** C1 is
not restated. C10 is not edited.

---

## Part 0 — what records exist at Level 2?

**None.** A Level-2 generate has no custody URL. Kong's
`record_decision` returns immediately when `custody_url` is empty
and never POSTs `/v1/ledger` and never appends `ledger_fallback`.
APISIX's forward Lua only posts the ledger inside the custody
block, which is omitted at Level 2. Apigee has no ledger hop.
There is no other sink.

C10's decision-precedence half **holds** at Level 2: the
classification is bound into configuration before any request
arrives. C10's **record** half does not: nothing durable is
written. C10 says an implementation whose records can be lost has
not recorded them. Never writing one is a stronger failure than
losing one. ADR-005's accepted window is the record sink down
*alongside* the policy service, not the absence of a sink as the
Level-2 posture.

C1 and C10 would both be relying on the other to carry recording.
Restating C1 by dropping "recorded" would open that hole while
looking tidier. That is why this task stops.

Level 1 on the adoption ladder is *observe: classify and stamp
spans, enforce nothing*. The reference does not stamp spans
either, and it does not write a decision record. The ladder is
describing a durable observation the implementation does not do.
Worth finding now; not this task's to implement.

## What was not done

C1 still reads, in the engine PRD: classification precedes
routing; no governed operation reaches its target before a
decision is recorded. The property 25 named — routed only if
classified — is not yet the letter. Level 2 execute still fails
that letter and still satisfies restated C10's precedence clause.

Dropping "recorded" would permit classify-and-record-nothing.
C10 does not close that at Level 2, because Level 2 records
nothing. The clause that would have closed it ("this does not
relieve C10") would have been a cross-reference onto a criterion
whose record half is already unmet there.

## The line worth recording

11a corrected C10 and did not ask whether any other criterion
rested on the same assumption. The answer was yes, it was one
criterion away, and it took a systematic audit eight tasks later
to find it. When a defect is found in one artefact, the cheap
next question is which other artefact was written by the same
hand on the same day with the same architecture in mind.

Part 0 is that question's second half: the neighbour criterion
does not currently carry the recording C1 would have dropped.

## C12 — the governed set

Reading 1 was unsatisfiable by construction. A route
added after generation outranks any generated catchall —
38 measured it, APISIX's added route at priority 100
beating the `/*` at priority 1 — so *reachable through
the gateway* would make conformance a timestamp rather
than a property of a deployment.

C12 now applies to the operations ctier governs: those
present in the composed description from which the
enforcement configuration was generated. A path
reachable at the enforcement point but absent from that
composition is outside this criterion.

The obligation that falls out of it: an implementation
MUST make the governed set discoverable — an operator
must be able to determine which operations are covered
without reading generated configuration. 38 described a
coverage manifest as the candidate mechanism. The
obligation is named. The mechanism belongs to the
implementation.

---

## C2 — not a default for the gap

Kong's global plugin assigns the undeclared default to
anything routable, including a path the composition does
not contain. Nothing in C2's text forbade that.

C2's undeclared default now applies to operations within
the composed description that carry no explicit tier
assignment. It is not a default for paths outside the
composition.

Without that sentence an implementation can satisfy C12
by letting C2 cover its gap — which is what Kong does
today. 26 refused exactly this shape when C1's recording
was going to lean on C10. The same refusal applies here.

---

## Undetermined is not Tier 4

C12 already said: refused, and recorded with the applied
tier undetermined. That is not the undeclared default.

An undetermined refusal records that no assignment was
found. A Tier 4 decision records that a maximally
consequential operation was refused. These are different
facts, and a ledger that cannot distinguish them cannot
tell a provisioning defect from a governance outcome.

Neither target does this today. That sentence is the
reason the engine task exists.

## The observation this pair earns

Seven criteria stated a mechanism where a property was
meant. Two now turn out to have stated a property
without its boundary, and **both were found by the same
probe** — a single request to a path nobody had thought
to send one to.

"Mechanism or property?" has been the standing question
since 24. This adds a second: **"and within what
scope?"** It is cheaper than the first, because a
criterion with no scope sentence is visible on reading,
whereas a mechanism masquerading as a property usually
is not.

## The nine

**Bound comparison —
interpret a bound as a
decimal.** Decline. A
second implementation that
parses the parameter as
an integer fails open on
`101.0` and `1.01e2`. The
author points at the named
MUST in validation.md and
the request corpus. That
is already written down.
No existing C-series
letter covers the parse.
The risk of not minting
one is acceptable: the
MUST already binds a
second implementation.
Adopting because the
hazard is real, or
because the corpus is
cheap, would be adopting
because it is true.

**No agent-facing URL.**
Decline. A second
implementation that emits
a pollUrl on a new
disposition leaves the
agent engaged. The author
points at the named MUST
in validation.md, and at
C5 and C9, which already
reference it. The
dispositions that exist
are covered. The MUST
covers ones not yet
written.

**C1 "recorded".**
Decline. A second
implementation that
classifies without a
ledger write still
satisfies C1: no governed
operation reaches its
target unclassified. The
record is evidence. C10
is the record. 1.15.0
already removed
"recorded" as the PRD's
mechanism. Adopting it
would undo that.

**C2 "granted scope".**
Decline. A second
implementation that
applies the undeclared
default to a
scope-reachable path
outside the composition
fails C2. The author
points at C2: the subject
is an operation in the
composed description, not
a granted scope.

**C3 no-runtime-input /
"+1 never past 4".**
Decline. C3 forbids
`x-ctier-escalate-to`
resolving below the tier
already reached. The 1–4
enumeration forbids a
tier past 4. The +1 cap
is this generator's
compiled consequence, not
the criterion. "No
runtime input may produce
a tier lower than the
declared tier" restates
C3 against the wrong
subject — declared, not
already reached.

**C4 occupancy.**
Decline. 1.15.0 replaced
where the human sits with
no decision path blocks
on human input. Occupancy
is C5 and the suspension
rule. Re-adopting
occupancy undoes 1.15.0.

**C7 "derived not
generated".** Decline.
C7 is the
duplicate-execution
property. Derivation is
one named way (1.8.0).
"Derived not generated"
is the engine's
mechanism. A second
implementation that
satisfies C7 another way
is conformant. The author
points at C7.

**C12 "bound to the
deployed interface
revision".** Decline.
C12 is coverage of the
governed set (1.12.0),
not a generator story.
Binding an assignment to
the composition it was
computed from is C13. A
second implementation
that covers the governed
set without that phrase
satisfies C12. The author
points at C12 and C13.

**C13's minting.**
Decline. Closed. 47
admitted C13 and wrote
that the specification
mints the letter. An
implementation proposes.
Historical. Nothing
further to adopt.

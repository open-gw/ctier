# 11a — restate C10

Task 11 built against C10 and found it described a request-time write
the compiled engine no longer performs. 1.1.9 restates the criterion as
the property that write was standing in for: **no operation executes
without a decision having been made.**

## Does the restatement change what any existing target must do

No. It changes what the document claims.

Kong already binds the decision into compiled configuration at deploy
time, writes evidence fail-open (and asynchronously relative to the
action, for Tier 1 and 2), and records an Attempt when persist cannot
reach custody. The durability clause names SQLite-as-v1 and a JSONL
fallback that survives a custody restart; it does not ask Kong to start
doing something new. The Envoy target, when it exists, is still free to
satisfy the same criterion by `ext_authz` evaluating synchronously
before the request proceeds — the restatement admits that idiom rather
than excluding it.

The criterion was describing something that was already true. That is
the best possible outcome of a restatement, and the reason not to write
"the decision is made at compile time": that sentence would have made
the intended Envoy target non-conformant by construction.

The classification-guide auditor FAQ used the old sentence. It now
matches.

## What 1.1.9 added that C10's old "before" had been carrying

Dropping "recorded before they are acted on" would have removed the
only implication that a record could not simply be buffered and lost.
Asynchronous plus non-durable is worse than the synchronous write C10
originally described. The durability clause closes that door. The
best-effort window — record sink down alongside the policy service —
is the limit ADR-005 already accepted, now said rather than implied.

## The pattern

C5, C6, C7, C9 and C10 have each now been built against. Each gap
pointed the unsafe way, and C10's was describing a mechanism instead of
the property it protects. That is the last of the five that had never
been exercised. C8's rejection branch remains, and cannot run until the
authorisation layer exists.

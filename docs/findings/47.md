# 47 — C13 is the thirteenth criterion

Spec **1.17.0**. Requires 43. Independent of the engine.
C13's requirement body is unaltered. Engine behaviour
was not changed. ADR-0009 already named C13; it
was not edited.

43 titled Digest discipline as C13. The letter
was already in the heading. A heading is not an
admission rule. This task writes the rule first,
then applies it.

---

## What a C-series criterion is

A requirement a second implementation must
satisfy, testable against a running deployment
or a compiled artefact. A validator-checked
rule is a requirement a document must satisfy,
testable against this specification's own
files. Those are different tests.

Appearing in `conformance.md` with declared
evidence is not the test. That names a document
location, and it would be circular. It is a
cost of admission. A criterion so admitted
obliges a declaration of evidence there,
including none.

The specification mints the letter. An
implementation may propose a requirement; it
does not mint the letter.

The rule is a property, not a location. Its
scope is requirements on an implementation's
behaviour. It does not admit a rule about the
specification's own documents, and it does not
admit a deployment condition the
implementation cannot make unavoidable.

---

## Applied to C13

Admitted. A second composer or generator must
produce the same digest from the same inputs.
That is testable against a compiled artefact
— the composition manifest, the ledger stamps.
It is not a rule about this specification's
own files.

Branch A.

---

## Mechanism or property

Mechanism. "Assignment binds to the digest"
and the current body — canonical JSON, raw-byte
per-input digests — name how the binding is
computed. The property is: an assignment
cannot be applied to a composition other than
the one it was computed from.

Not restated here. That is a follow-up task.
39's rule stands.

---

## Scope

The digest is over the composition. That
composition is the governed set by definition.
A path outside the composition is outside the
digest — there is no assignment to bind.

---

## Evidence

None. Configured, Derived, and Observed do not
apply. The corpus does not assert a digest
value. Schema checks the string form, not the
bytes. 1.4.0 already said so.

---

## Who minted the letter

Engine `9644fd8` (5 September): "New
conformance criterion, C13." Digest discipline
landed in the specification the next day
(`c8407a4`, 6 September) with no letter. The
first spec-prose C13 was a 1.4.0 parenthetical.
43 attached the letter to the heading.

The same defect as 46 — the PRD titled C1, C3
and C4 while the specification stated none —
in the opposite direction. A property of how
the two repositories relate: the engine can
name a criterion the specification has not
minted.

The admission rule says who may mint: the
specification does. An implementation
proposes.

## The observation this task earns

43 found 33 identifier classes. This task
writes an admission rule for exactly one of
them. C13 is the first time the absence of
that rule cost anything: a letter existed
across fourteen minor versions without a test
that would have said whether it belonged.

The audit of 25, 26, 39 and 42 covered twelve.
C13 was not among them. Its classification
was recorded after that audit closed.

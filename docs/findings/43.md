# 43 — every identifier, and whether it requires anything

Spec **1.16.0**. Requires 42. Independent of the engine.
No criterion reworded. Engine behaviour was not changed.

42's tell: a name that never appears beside a requirement is
not a requirement. C1 and C4 were named everywhere and
required nowhere. C3's requirement existed unattached to
its letter. This is the first pass that goes looking before
anything breaks.

The corpus is `spec/` — README, validation, conformance,
extensions, headers, ladder, schemas, examples,
`consequence-tiered-api.yaml` — plus `docs/adr/0009` because
the spec points at it. `docs/classification-guide.md` is not
spec-pointed; it was read and not inventoried as normative.
`runtime-suite` and `record-source` are not specification
identifiers.

## Whether this check could be mechanised

Yes, enough of it to have caught this pass in an afternoon.

It would have to read:

- every heading and every MUST in `spec/*.md`
- every `enum`, `const`, `$id`, and required property in
  `spec/schemas/*.json`
- every `x-ctier-*` key and named component in
  `consequence-tiered-api.yaml`
- ADR-0009, because the spec points at it

A join of schema tokens against headings would have listed
C2 (no `C2 —` heading), C13 (letter only in parentheses),
and every schema enum that never appears in prose —
`retry_later`, `refuse-and-suspend`, the six escalation
reasons, `operationAnchor`. "Is this sentence a requirement"
still needs a reader. Do not build it here.

## The observation this pass earns

This is the first pass that goes looking before anything
breaks. It did not find nothing.

C2 and C13 were the same defect 42 found in C3: a
requirement living under a descriptive title, the citation
identifier elsewhere or in brackets. Twenty-two further
names are in the schemas, the example, or the engine's
measurement taxonomy, and have no sentence. The check earns
a place in the release routine.

It took fifteen minor versions to run a grep against the
project's own vocabulary. C1 sat in lists through 1.14.0.
C2 sat in a sentence and never in the criteria list. C13
was titled Digest discipline while ADR-0009 and the schema
`$id` already called it C13. The schemas grew enums —
dispositions, escalation reasons, agent actions — and the
prose never met them.

Either answer was worth writing down. This is the one that
is not comfortable.

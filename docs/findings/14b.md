# 14b — the boundary contract, and what ctier does not enforce

Spec **1.5.0**, corrected after the first landing named emit⊆strip
(a mechanism) instead of the namespace property.

## Answers

**Stop condition.** No emitted header carries a token, an approver
identity, or a decision a backend could take as permission. 14a
removed `x-ctier-approver` and `x-ctier-agent`.

**The invariant.** The property is: no header in the `x-ctier-*`
namespace that reaches a backend may be agent-supplied. The
enforcement point MUST strip the entire namespace on ingress,
regardless of what this target emits. Emit⊆strip holds vacuously
for names the target does not emit — which is how `x-ctier-correlation-id`
on Apigee and APISIX closed sets was going to ship as an engine
follow-on while the spec named that header the join key. Kong is
safe because a prefix strip catches the namespace by construction.
Closed sets are a **conformance failure** against 1.5.0.

**Correlation id.** MUST on any request that reaches the backend,
not only custody execute. 14a's recovery still holds for approved
execute. Ordinary Tier 1/2 could not join a decision record at all;
auditability is a headline claim. The reference implementation emits
the header only on custody's path today, declared (same class as
Apigee's unproven differential). Engine task to follow.

**Idempotency-Key.** Custody emits the derived C7 key. The
enforcement path does not. An agent-supplied `Idempotency-Key` is
forwarded; nobody strips it. That hands the duplicate-execution
defence to the party it defends against. 1.5.0 requires the derived
key on every backend request and forbids an inbound key from
reaching the target. Reference implementation: custody only,
declared.

**Two names.** Downstream was `X-Correlation-Id`, upstream
`x-ctier-correlation-id`, same value. The downstream name sits
outside a prefix strip. 1.5.0 uses `x-ctier-correlation-id` both
ways. Inbound `X-Correlation-Id` and `X-Ctier-Tier` MUST be stripped
as aliases. The example 202 header is renamed. The reference
implementation still relays `X-Correlation-Id` on 202.

**Part 4.** Worth closing. The corpus can agree on disposition while
Apigee/APISIX fail the namespace property. A new case shape is a
review decision. Not taken here.
